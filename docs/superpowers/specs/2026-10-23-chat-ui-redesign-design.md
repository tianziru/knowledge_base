# 灵犀智库问答前台 UI 改版 · 设计说明

日期：2026-10-23  
状态：已批准并实现

## 目标

- 观感与导入后台同系（石板侧栏 + 天青强调），全高工作台，不再居中小卡片。
- 功能加厚：本机会话列表、新建对话、快捷提问、复制答案、停止生成。
- **阶段进度不对客户展示**：回答过程仅 typing /「正在思考…」，只呈现最终答案（可含配图）。

## 范围

- 修改：`app/query_process/page/chat.html`
- 会话列表：`localStorage`（无需新后端 API）
- 不改：LangGraph、鉴权、用户上传图片提问

## 非目标

- React/Vue 重写
- 服务端多用户会话中心
