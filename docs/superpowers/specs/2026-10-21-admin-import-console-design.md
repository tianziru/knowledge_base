# 灵犀智库导入后台控制台设计

**日期：** 2026-10-21  
**状态：** 已批准（用户确认「按这个做」）

## 目标

将现有单页 PDF/MD 上传页升级为**管理后台壳子**：侧栏导航、概览统计、多格式真入库、任务筛选与常用后台能力；品牌保持「灵犀智库」。

## 方案

采用 **单页 SPA 壳子（方案 A）**：仍服务 `import.html`，左侧栏 + 右侧面板切换；服务端将非 PDF 文档统一转为 Markdown 后进入现有 LangGraph。

## 范围

### 做

1. **后台布局**：深色侧栏（概览 / 文档导入 / 任务中心 / 格式说明）+ 顶栏模块名；底部链到问答服务（8001）。
2. **文档导入**：拖拽上传；`accept` 扩展为 pdf/md/txt/docx/pptx（及合理别名）；保留进度条与日志轮询。
3. **多格式入库**：
   - `.pdf` → 现有 MinerU 路径
   - `.md` → 现有 MD 路径
   - `.txt` / `.text` → 包装为 MD
   - `.docx` → python-docx 抽文本 → MD
   - `.pptx` → python-pptx 抽幻灯片文本 → MD
   - `.doc` / `.ppt` → 尝试失败时任务标记失败并给出明确错误（不引入重型转换依赖）
4. **概览**：基于任务列表的今日/累计、进行中/成功/失败统计与最近任务。
5. **任务中心**：状态筛选、文件名搜索、移除/清空。
6. **格式说明**：静态说明各格式处理方式。
7. **API**：可选 `/stats` 聚合；上传校验扩展名；服务描述更新。

### 不做

- 登录/权限
- 知识库检索结果管理（问答仍在 8001）
- 批量文件夹扫描、定时同步
- 另起 React/Vue 工程

## 架构

```
上传 → 本地保存 → MinIO(可选) → LangGraph
  node_entry:
    pdf → is_pdf_read_enabled
    md  → is_md_read_enabled
    txt/docx/pptx → 转 MD 落盘 → is_md_read_enabled
  → 现有 md_img → split → … → milvus
```

转换逻辑放在可单测的工具模块，由 `node_entry` 调用，避免改条件路由图结构。

## UI 结构

| 面板 | 内容 |
|------|------|
| 概览 | 统计卡片 + 最近任务 |
| 文档导入 | 上传区 + 当前会话任务进度 |
| 任务中心 | 全量任务 + 筛选/搜索/清空 |
| 格式说明 | 支持矩阵与说明 |

`localStorage` key 升为 `kb_import_tasks_v4`（扩展格式后刷新兼容策略：可迁移旧 v3 或空列表重建）。

## 依赖

- `python-docx`
- `python-pptx`

## 成功标准

1. 后台壳子四面板可切换，刷新后任务可恢复。
2. txt/docx/pptx 可走通入库（依赖环境与下游服务正常）。
3. 任务中心可按状态筛选与按文件名搜索。
4. 不支持格式在入口失败并可见失败状态。
